## About

**CelestiaADS** is a modern discovery platform built for Discord communities.

The goal is simple: help communities **get discovered, grow their audience and improve their visibility**, while giving server owners powerful tools to manage their presence.

CelestiaADS combines:

* Server discovery
* Categories and tags
* Visibility rankings
* Voting
* Bumps
* Recommendations
* Analytics
* Server customization
* Discord automation

> **Discover. Grow. Customize.**

---

## ✦ Discovery

Find communities that actually match what you're looking for.

### Server Directory

Browse Discord communities through a clean and organized directory.

* Categories
* Subcategories
* Tags
* Search
* Filters
* Public server pages
* Similar server recommendations

### Visibility

Give communities different ways to increase their exposure.

* Bumps
* Visibility votes
* Rankings
* Server activity
* Discovery recommendations

Votes for **visibility** and **reviews** remain completely separate to keep rankings meaningful.

---

## ✦ Dashboard

CelestiaADS provides server owners with a centralized dashboard to manage their community.

### Manage

### Analytics

Track how your community evolves over time.

* Member growth
* Visibility
* Votes

* Historical statistics

## ✦ Discord Integration

CelestiaADS is deeply connected to Discord.

The Discord integration allows communities to interact with the platform directly from their server.

```text
Discord Server
      │
      ▼
 CelestiaADS Bot
      │
      ├── Server discovery
      ├── Bumps
      ├── Votes
      ├── Statistics
      ├── Community tools
      └── Automation
      │
      ▼
 CelestiaADS Platform
```

## ✦ Platform Architecture

CelestiaADS is designed as a connected ecosystem rather than a simple server directory.

| Layer            | Purpose                                    |
| :--------------- | :----------------------------------------- |
| **Web Platform** | Discovery, server pages and public content |
| **Dashboard**    | Server management and analytics            |
| **Discord Bot**  | Discord integration and automation, votes and advanced statistics        |
